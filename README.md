# WriteSpace 留白

面向社区需求与互助匹配的可运行原型。所有人物、活动、互动均为演示数据。

## 启动

需要 Node.js 18 或更新版本，无需安装依赖。

1. 将 `.env.example` 复制为 `.env`，填入 `AI_API_KEY`。如网关使用其他模型名，修改 `AI_MODEL`。
2. 在项目目录运行 `npm run dev`。
3. 打开 `http://localhost:4317`。

AI 请求由 `server.mjs` 代理，密钥不会发到浏览器。没有密钥、网关不可用或模型名不兼容时，界面会明确标记为“本地规则匹配”，其余原型仍可体验。

## 演示路径

浏览社区需求 → 搜索或筛选 → 点击“发布需求” → 填写标题、描述与时间地点 → 点击“发布并寻找匹配” → 查看匹配理由 → 打开详情并点击“我想参与”。

发布内容与参与状态暂存在当前浏览器的 localStorage。原型没有真实账户、通知或线下预约；如需清空演示数据，可使用页面中的“重置演示”。

## 后续落地

接入账户与社区认证、持久化数据库、双向同意、站内消息、举报审核、场地与时间确认。AI 匹配可从当前结构化候选列表扩展到真实社区供需库；始终保留可解释理由与人工确认。

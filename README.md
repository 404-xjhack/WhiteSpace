# WhiteSpace 留白

想做一件事，找到一起做的人。留白是一个附近协作原型，从“我想做什么”出发，帮助社区里的兴趣、技能与需求互相发现。内置人物与活动是明确标注的虚构演示资料；地图使用真实高德底图，个人发布只保存在当前浏览器。

我们重构的，是“找人一起做一件事”这件再普通不过的事情。想修好一把旧椅子、学摄影或认识街坊，往往要先在群聊和社交平台发消息，等待有人看到，再一个个确认是否合适。身边有需要，也有时间、能力和兴趣，缺少的是让它们互相发现的方式。

用户描述想做的事或可以分享的能力，补充时间、地点等条件，通过 AI 或本地规则查看伙伴建议、具体理由和第一步，再决定是否表达参与意向。关注的是现在可以一起开始的人，以及双方能带来的帮助与收获。技术栈为原生 HTML/CSS/JavaScript、无依赖 Node.js HTTP 服务；无需打包或安装第三方依赖。

内置示例包括一起包饺子、街区散步、修旧椅子、亲子动手、写作交流与手机摄影。王阿姨的饺子样例另提供六步手工制作体验和本地学习记录。当前匹配候选为六条虚构资料，地图可展示地点和步行路线，但尚未实现真实邻居的地理匹配、消息或实际组队。

## 社区价值

留白希望让零散的时间、技能、兴趣与经验，变成可以开始的活动、互助与协作。会修家具的人可以帮助旧物继续使用，愿意分享手艺的人可以遇见想学的人，新居民也可以找到愿意同行的街坊。发布说明中还可以表达可带来的工具、设备或空间；当前没有专门的资源调度系统，也没有真实社区试点的成效数据。

首页保留原有工作台，在其后依次解释今天的发现困难、使用流程、社区价值与长期愿景。“了解留白”可直接跳到说明，进入地图时隐藏说明区与页脚。

## 当前功能

- 外观支持「浅色／深色／跟随系统」，默认跟随系统。首页、时间胶囊、独立与嵌入式工坊、3D 街区控件及地图面板保持一致；已打开的工坊也会实时同步。

- “今天想参与什么？”：选择短／中／长的时间倾向、同行人数（含自己）和主题，根据这些条件从他人已经发布的想法中获得最多三条推荐。支持材料、出行、轻量活动与文字补充，查看原发布并直接表达参与意向；未知条件明确标为待确认。AI 筛选推荐与本地发布筛选分别标记来源，刷新后可恢复。

- [手工饺子工坊](docs/DUMPLING_EXPERIENCE.md)：从王阿姨样例详情点击「进入饺子工坊」，用六步导览、模型变化与轻量拖拽了解传统制饺。关闭后返回原详情，重新打开恢复学习记录；也可独立访问 `/dumpling-house.html`。资源本地化，支持图文降级和同源 iframe 接入。

- 「生活时间胶囊」：完成饺子工坊六步后，在工艺回顾中确认自己的文字作品，回答「哪个瞬间让你愿意继续？」和「下次想保留什么、换一种什么做法？」，保存为完整作品卡。首页和独立工坊的「时间胶囊」入口可按时间回看，重新打开完整作品与感受，并导出中文 `.txt` 文件。只记录具体尝试，不对人生、能力或成长打分。
- 时间胶囊空状态提供「逛逛 3D 饺子店」入口，可直接进入独立街区场景并点击光柱观察虚构的互助需求；场景没有初始引导页，左上角 Logo 返回首页。这是观察型演示，不会发布真实需求或保存胶囊。

- 按「我想做一件事」「我能分享或帮忙」区分文案与校验，短标题和短说明也可发布。
- 分享的“希望获得”由 AI 从标题与说明提炼，展示原文依据，允许修改后确认；未提及的诉求显示“未说明”，已有个人分享可重新提炼。
- 分类逐项添加／移除，支持自定义「其他」；列表、详情、搜索和匹配保留全部分类。
- 具体日期或每周时间段；发布时可在真实地图选公共集合点，也可仅填写地点说明而不显示在地图。能力分享可选择时间和地点可协商。
- 参与人数可协商、明确总人数或人数范围；演示资料可保存身份说明与选填年龄，年龄默认不公开。
- 发布时间实时更新，参与意向可取消；刷新后恢复最近匹配，并从每条「我的发布」详情继续查看或重新匹配。
- 从「我的发布」详情删除个人内容，需再次确认；同步移除该条匹配记录，刷新后保持删除结果。取消删除保留原内容，浏览器保存失败时可重试。
- AI 与本地规则匹配均标记来源；AI 或接口失败时保留可演示的本地匹配。
- 匹配优先比较正文中的需求与实际帮助，自定义标签仅作辅助；可展开全部候选，查看相关但时间冲突的发布。
- 街区地图只使用真实高德底图：进入时以街区尺度申请浏览器定位；拒绝或失败时可搜索地点、按住拖动地图并点选出发点。拖动松开即停；再次点击地图即可更换出发点，已选任务的路线随之重算。出发点不会保存。
- 地点搜索以纵向列表显示地点与地址；发布者可点地图、搜索或拖动标记确认公共集合点，并写明“见面后先做的一小步”。6 条内置任务每次加载时随机分配在学军紫金港附近的示意点，与真实底图叠加。初始不计算或显示路线；用户点击任务点后，才请求并以蓝色显示到该任务的步行路线。再次点击已选任务会清除路线，地图上的“隐藏路线／显示路线”也可控制显示。演示点及其路线仅用于功能参考，不是实际赴约指引。个人发布保留真实选定坐标、路线及编辑／删除能力。

`public/model.js` 提供前后端共用的字段校验、时间格式和规则匹配；`public/map-ui.js` 负责列表／地图视图切换，`public/real-map.js` 负责真实地图、定位、路线和选点；`public/experience-planner.js` 提供他人发布筛选、参与建议和推荐缓存校验。`server.mjs` 负责静态文件、AI 代理、高德 JS 安全密钥代理以及服务端地点／路线请求。

`public/time-capsules.js` 负责胶囊校验、独立本地存储与文字导出，`public/time-capsule-ui.js` 和 `public/time-capsules.css` 提供主站与工坊共用的表单、历史列表和完整作品卡；不新增依赖或后端接口。

时间胶囊保存界面与工坊最后的工艺总览沿用站内弹窗的滚动条：6px 圆角滑块、透明轨道、隐藏原生箭头，距弹窗右边缘 8px，鼠标停留或键盘操作时加深。标题及底部操作保持可见，仅正文滚动；桌面与手机按各自的内容留白对齐。

## 外观主题

首页和独立工坊的页头、工坊弹窗头部、3D 街区右上角都提供「外观」选择器。手机页头为外观选择保留单独一行，不挤掉原有导航。「跟随系统」读取 `prefers-color-scheme` 并监听系统变化；手动选择浅色或深色后不会被系统变化覆盖，切回跟随系统立即恢复自动更新。

深色界面使用中性炭灰背景与面板，绿色用于主要操作与选中状态。桌面外观选择器位于原右侧导航的左边，导航保持右对齐和原有间距；手机仍保留原导航行。高德地图的原始标识和版权信息在深色下加浅色底，保留完整标识、链接及原位置。

偏好字符串独立保存在 `whitespace.theme.v1`，同源页面刷新、跳转和已打开的标签页保持一致。「重置演示」及工坊「重新开始」保留外观偏好。主题切换只更新配色和地图样式，不重建页面、清空表单、重新生成匹配、改变学习记录或修改时间胶囊；3D 街区时间、灯光和视角继续由原有控件决定，场景材质保留原色。

`public/theme.js` 在样式和业务模块之前同步解析偏好，设置实际主题、原生控件的 `color-scheme`、根背景及 `theme-color`。`public/theme.css` 共用配色和选择器样式；已有页面样式按主题覆盖固定浅色，滚动条保持原有 6px 宽度、圆角、透明轨道和 hover/focus 行为。按钮在切换主题时即时更新颜色，随后恢复原有悬停过渡。

主站通过独立的同源主题消息同步工坊 iframe，子页在首次绘制前也读取父页状态。偏好保存失败时仍可切换当前页面及已打开工坊，并显示提示；刷新可能恢复旧偏好，完全禁止读取时默认跟随系统。持久化只在同一浏览器、同一站点来源内生效，不能保证被禁用的本地存储保留选择。

高德地图浅色使用 `amap://styles/normal`、深色使用 `amap://styles/dark`。浏览地图和公共集合点地图初始化时读取最新主题，已存在实例使用 `setMapStyle()` 更新；样式调用失败保留原有地图、路线和选点。[高德 JS API 2.0 官方地图样式文档](https://lbs.amap.com/api/javascript-api-v2/guide/map/map-style)。

## 启动

需要 Node.js 18 或更新版本，无需安装依赖。

1. 可直接体验本地规则匹配。如需 AI，将 `.env.example` 复制为 `.env`，填入 `AI_API_KEY`；按网关调整 `AI_API_URL` 和 `AI_MODEL`。
2. 在项目目录运行 `npm run dev`。
3. 打开 `http://localhost:4317`。

### 配置真实地图（可选）

在[高德开放平台控制台](https://lbs.amap.com/api/javascript-api-v2/prerequisites)创建应用并添加第一把 Key，服务平台选择 **Web端（JS API）**，取得 Key 和配套的安全密钥。再添加一把 **Web服务 API** 类型的 Key，供地点搜索和步行路线使用；两类 Key 不可互换。将 `.env.example` 复制为 `.env`，填写：

```dotenv
AMAP_WEB_KEY=你的Web端JS_API_Key
AMAP_SECURITY_CODE=对应的安全密钥
AMAP_SERVICE_KEY=你的Web服务API_Key
```

如控制台要求绑定域名，按其提示配置本地 `localhost` 与正式部署域名。修改 `.env` 后重启 `npm run dev`，打开“街区地图”。`AMAP_WEB_KEY` 是会提供给浏览器的 Web 端 Key；安全密钥留在服务端，透过同源 `/_AMapService` 代理用于底图请求。`AMAP_SERVICE_KEY` 仅留在服务端，由本项目的 `/api/map/places`、`/api/map/walking` 访问高德 Web 服务，均不能提交到仓库。浏览器定位需要许可，正式部署应使用 HTTPS；未授权时仍可手动搜索和选点。[高德安全密钥说明](https://lbs.amap.com/api/javascript-api-v2/guide/abc/jscode)、[Web 服务步行路线文档](https://lbs.amap.com/api/webservice/guide/api/newroute)

仅填写 Web JS Key 和安全密钥时，真实底图与手动点选集合点可用；搜索和步行路线会明确提示还需要 Web 服务 Key。

AI 请求由 `server.mjs` 代理，密钥不会发到浏览器。默认使用 TokenDance（词元跳动）的 `deepseek-v4-flash`，接口为 `https://tokendance.space/gateway/v1/chat/completions`，参考[平台快速入门](https://tokendance.space/docs/quickstart)。AI 匹配和“希望获得”提炼共用这份配置。没有密钥、超时、网关不可用或返回异常时，匹配界面会明确标记为“本地规则匹配”并说明原因。

配置必须写入被 Git 忽略的 `.env`，`.env.example` 只保留空密钥示例。`AI_API_URL` 为完整的 Chat Completions 请求地址。按[平台文档](https://tokendance.space/docs/quickstart)创建 TokenDance 的 API Key，填入 `.env` 的 `AI_API_KEY`；DeepSeek 官网密钥不能用于这个网关。模型 ID 使用平台[公开模型目录](https://tokendance.space/gateway/v1/models)中的 `deepseek-v4-flash`。更换配置后重启服务。

```dotenv
AI_API_URL=https://tokendance.space/gateway/v1/chat/completions
AI_API_KEY=
AI_MODEL=deepseek-v4-flash
PORT=4317
```

“希望获得”提炼使用同一网关，只发送个人分享的类型、标题和详细说明，不发送年龄、身份或地点。只提炼明确写出的诉求，并要求返回可在原文找到的连续片段；没有明确诉求时返回空值。发布前可核对依据、修改或留空，确认后才保存。AI 失败时提示原因，仍可手动填写或留空发布；不将固定文案或本地推测标记为 AI 结果。历史分享可从详情点击“AI 提炼希望获得”，保存后为原发布重新匹配，其他原字段保留。

本地匹配先从标题、说明及对应的需求／能力字段提取中文词语和少量技能别名，判断内容是否相关，再排除明确的技能冲突和时间冲突；按正文证据、供需互补、时间交集、地点及少量标签加分排序。相同标签或不同发布类型本身不足以推荐；加入无关的 `test` 标签不会排除已有的相关人选。分数是规则参考值。默认展示前三项，其余相关候选可展开；时间冲突单独说明，未确定的时间地点仍需协商。AI 可推荐本地词表未覆盖的人选，但也需满足时间和明确技能约束；AI 以外的本地补充候选各自标记来源。

桌面首页的需求列表与匹配栏各自滚动，无需先把需求列表拉到底。两栏使用内嵌的圆角细滚动条和透明轨道，内容与滚动条保留 6px 空隙，鼠标停留或键盘操作时滑块加深。首页间距同步自原项目提交 `46946f6`；发布、详情及推荐等弹窗使用相同滑块与轨道，发布与详情弹窗的滚动条距右边缘 8px，保持内容对齐，弹窗头部和底部按钮保持可见。匹配列表上方显示“展开其他候选（数量）”，展开后可收起；只有确实存在未显示候选时才显示这个按钮和对应的 AI 提示。手机继续使用整页滚动。

## 演示路径

地图演示：配置两类高德 Key 和安全密钥并重启 → “街区地图” → 初始只显示学军紫金港附近的随机示例任务，不自动画路线 → 定位或点击地图选出发点 → 点击一个任务点，查看蓝色步行路线 → 再次点击该点关闭路线，或用地图内按钮隐藏／恢复 → “发布附近的事” → 填写标题、说明、分类和时间 → 地点选“在地图选择公共集合点” → 搜索或点击地图，拖动标记微调，确认不是住宅／私人地址 → 填写“见面后先做的一小步” → 发布。个人任务标记和任务卡立即出现。点击地图空白处可改变出发点并重算已选任务路线；随机示例点与路线不可用于真实赴约。点“编辑”可修改个人任务，点“删除”需二次确认。未配置地图时显示配置提示，列表与匹配仍可使用。
首页“今天想参与什么？” → 选择短／中／长的时间倾向、同行人数（含自己）与主题 → “找适合我的想法” → 查看最多三条他人发布及理由 → 展开“参与建议与待确认条件” → “查看发布” → “我想参与”。也可在推荐卡片直接表达或取消参与意向，无需先创建自己的发布。演示时选择“旧物新生”、补充“想了解木椅修复”，可查看陈师傅已发布的木工分享及其原始时间地点。

推荐候选来自当前社区发布库（原型为 `public/data.json` 中六条虚构人物发布），排除本人的发布。人数上限、主题、材料、出行方式及体力要求用于筛选，已知冲突时排除，不自动放宽。短／中／长只表示本次的投入倾向，不对应固定分钟，不按时长淘汰发布，也不替用户安排日期；“长”不表示长期或周期性参加。已注明的单次时长仅用于候选之间的相对排序，具体日期与参与时长由用户查看原发布后自行挑选并和对方确认。未写明单次时长或材料等条件的发布保留候选，并明确要求向发布者确认。每周交流时间段不等于单次参与时长，不据此推测完成整个活动所需的时间。

同行人数表示你带来的总人数，包含自己；原发布人数包含发布者。一个人也可以寻找多人活动，筛选只核对同行人数加发布者是否超出已知上限，实际余位和人员组成仍需确认。“不添购材料”核对已注明的材料要求，未注明的要求保留并提示确认；“不外出（仅线上）”排除已明确线下地点的发布，地点待定的发布需确认能否线上参与；“轻量活动”排除明确不符合的发布，未知体力要求需确认。

`POST /api/recommend-experiences` 使用现有 AI 配置，只发送条件和筛选后的原发布。AI 选择已有发布 ID、解释理由并给出参与建议；标题、发布者、说明、时间地点等事实由本地保持不变。无依据的分钟／小时、时间灵活或室内外皆可等保证，以及从“长”推测长期参加的返回会被拒绝并回退。没有密钥、18 秒服务端超时、网关失败或无效返回时显示“本地发布筛选”；浏览器在断网或 22 秒超时后也可筛选已载入的发布。文字补充最多 160 字，本地推荐为此入口单独设计排序：优先比较兴趣正文，区分想参与和明确拒绝的内容；再参考发布的参与角色、新手说明、已有材料和投入线索，相近分数适当保留主题多样性。拒绝内容与发布相关、且没有同时感兴趣的内容时排除；有部分内容冲突则提示核对。原项目正文词语与技能别名继续共用，不改变普通发布匹配算法。推荐理由引用原发布的内容线索，不把线索写成确定时长；其余文字限制仍需自行核对。社区列表加载失败但推荐接口可用时，仍可查看接口返回的原发布并记录意向。

最近条件、推荐、来源和生成时间保存在 `whitespace.today.v1`。刷新后重新打开入口即可恢复，不自动再次调用 AI；超过 24 小时、版本过旧、内容损坏或原发布库变化时忽略建议，保留有效条件；旧 15／30／60 分钟条件分别迁移为短／中／长，旧建议重新筛选。关闭弹窗、修改条件和重置演示会取消旧请求，晚返回结果不会覆盖当前条件。“重置演示”清除推荐与参与记录。参与意向复用现有本地存储，不发送真实通知或预约。

王阿姨「周末一起包饺子，我来教和面擀皮」→「查看详情」→「进入饺子工坊」→ 完成六步操作或任意选择工序 →「返回详情」。擀皮每次有效拖动最多完成一次擀压，共三次；导览与自由观察隐藏屋顶和灯笼，漫游时显示，光照固定。学习记录与参与意向各自保存，主站「重置演示」同时清空工坊进度；工坊内「重新开始」只重置制作体验。

时间胶囊演示：完成六步操作 → 回顾页「保存为时间胶囊」→ 确认标题并写下自己的文字作品 → 回答两个短问题 →「保存时间胶囊」→ 查看完整作品卡 →「重新打开」或「导出 .txt」。刷新首页后，从顶部「时间胶囊」找到刚才的作品；多次保存按时间从新到旧排列。工坊当前没有既存的用户文字作品，因此首次需要自行填写；共用保存入口支持传入已有作品自动带入，草稿可在保存前修改，工艺说明不会作为用户作品填入。

胶囊仅使用 `whitespace.capsules.v1`，与原有发布、匹配、推荐及工坊进度分开。主站「重置演示」同时清空时间胶囊，刷新后保持空状态；清空失败时提示重试。工坊「重新开始」只重置制作体验，保留已保存的胶囊。空作品或未填写感受时提示具体字段；保存失败保留当前表单，可关闭后在同一工坊页面重新打开并重试，连续点击不会重复保存。读取失败或历史中有损坏记录时显示提示，仍可查看其中完整的胶囊，并阻止保存覆盖原记录。导出使用 UTF-8 BOM 与 CRLF 换行，文件包含标题、体验名、浏览器本地保存日期、全文及两条感受。

浏览与搜索 → 点击右上角“发布想法” → 选择“我想做一件事”或“我能分享或帮忙”，也可填写社区示例 → 添加分类、选择时间地点，按需设置人数和演示资料 → “发布并找伙伴” → 查看理由与第一步 → 打开对方详情 → “我想参与” → “取消参与意向” → 再参与。

选择“我能分享或帮忙”后，“发布并找伙伴”先打开“确认希望获得”，自动提炼，核对或修改后点击“确认并发布”；取消会返回原表单并保留填写内容。旧个人分享中的固定“寻找适合的分享对象，具体交流方式见说明”已清空，可重新提炼；演示人物的人工资料保留。

刷新页面仍能看到最近匹配。通过“我的发布”筛选打开任意个人内容，点击“查看上次匹配”或“寻找匹配”，再用匹配面板的“重新匹配”更新结果。匹配面板的“调整活动时间”或个人发布详情中的“调整时间”可修改同一条发布，保存前预览所选日期／星期和时间段，保存后提示实际时间并自动重新匹配；正文、分类、人数、演示资料及原发布时间保留，取消不保存。具体日期同时显示星期，便于理解它与每周安排是否重合。

缓存同时校验算法版本、对应发布及匹配输入，旧版本或内容变化会重新生成，原有发布保留。修改代码后需重启 Node 服务并刷新页面，使前后端使用同一版本。

本次社区示例文案更新使用 `content-v3` 匹配缓存版本；旧推荐会重新生成，个人发布、演示资料、参与意向、工坊进度和时间胶囊保留。已有用户自己写下的内容不作改写。

删除个人内容：打开「我的发布」→「查看详情」→「删除发布」→核对标题并「确认删除」。取消或按 Esc 返回详情，不修改内容。确认后移除该条发布及其匹配缓存，列表和发布数量立即更新；若正在匹配这条内容，会取消请求并恢复匹配入口，晚返回的结果不会重新出现。删除其他个人发布不会影响当前匹配，其他发布、演示人物、个人资料和参与意向保留。删除仅作用于当前浏览器的本地记录，没有账户或服务器删除接口。

人数包括发布者，范围为 1–50 人；身份说明选填，默认“社区成员”；年龄选填，接受 1–120 的整数，只有勾选公开才随本次内容展示。资料随成功发布保存，之后发布默认沿用；已有发布保留发布时的资料。

发布时间在 60 秒内显示“刚刚”，一小时内显示分钟数；同一天显示小时数，上一自然日显示“昨天”，更早显示日期（采用浏览器本地时间）。列表与详情每 30 秒更新，回到页面时也更新。旧数据缺少真实时间且只有“刚刚”时显示“发布时间未知”，原有演示相对文案继续兼容。

发布内容、演示资料、参与状态、每条内容的最近匹配、最近体验推荐及时间胶囊暂存在当前浏览器的 localStorage。原型没有真实账户、通知或线下预约；“重置演示”会清空这些本地记录。

## 已知限制

匹配候选为内置的六条演示资料，本地记录不会同步至其他浏览器。中文分词与技能别名不能覆盖所有语义，仍可能漏掉没有共同词语的相关内容；推荐需双方确认。周安排目前一次选择一个活动日，时间段需在同一天内。真实地图必须联网且有有效高德凭证，未配置 Web JS Key 与安全密钥时不可选点；未配置 Web 服务 Key 时不可搜索或计算步行路线。地图上的内置任务点每次加载随机分配，仅供演示，不是可赴约的地址；没有真实任务池、账号、通知或跨设备同步。出发点仅在内存中用于当前路线计算，不会被保存；个人发布的公共集合点会保存在本机 localStorage。目前没有真正跨用户的地理匹配，也未接入 SBERT 或 all-MiniLM。

时间胶囊当前接入实际可完成的饺子工坊，聚焦文字作品与两条感受，不包含推荐、评分或跨设备同步。未保存的草稿只保留在当前工坊页面内，刷新或离开工坊后不会恢复；已保存胶囊在刷新后保留，但清除浏览器站点数据会删除本地记录，可提前导出备份。损坏历史不会自动修复；可恢复原存储数据，或用首页「重置演示」清空后重新保存。

AI 应该让人与人的协作更容易。
